# ADR_002 - USE PRISMA

## Status
Approved

## Context
Need ORM for database access.

## Decision
Use Prisma for:
- Type-safe queries
- Auto-generated types
- Migration management
- Schema visualization

## Consequences

### Positive
- Excellent TypeScript support
- Great developer experience
- Good documentation
- Active community

### Negative
- Learning curve
- Migration complexity
- Bundle size

## Alternatives Considered
- TypeORM: Less type-safe
- Drizzle: Less mature
- Raw SQL: No type safety
